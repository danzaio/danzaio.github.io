04Process

A product is done when it can be used, trusted, and changed.

The work is not done when code compiles or a demo runs. It is done when the product path is tested, the evidence is visible, and the next maintainer can understand what changed.

  1. 01

    Use

    The product solves the customer or team workflow without needing a demo script.

    WORKFLOW
  2. 02

    Operate

    Accounts, data, payments, integrations, approvals, and outputs are visible enough to run.

    OPERATIONS
  3. 03

    Change

    A maintainer can adjust the system without reverse engineering it first.

    HANDOFF
01 / 03

If users cannot use it, operators cannot run it, and maintainers cannot change it, it is not finished.

The product passes when the workflow is clear, risky actions are visible, and another maintainer can change it without guessing.
