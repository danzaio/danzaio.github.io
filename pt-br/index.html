04Processo

Um produto está pronto quando pode ser usado, confiado e alterado.

O trabalho não termina quando o código compila ou a demo roda. Termina quando o caminho do produto foi testado, a evidência está visível e o próximo maintainer entende o que mudou.

01

Usar

O produto resolve o fluxo do cliente ou do time sem depender de script de demo.

Fluxo
02

Operar

Contas, dados, pagamentos, integrações, aprovações e saídas ficam visíveis o suficiente para operar.

Operações
03

Mudar

Um maintainer consegue ajustar o sistema sem fazer engenharia reversa primeiro.

Handoff

Se usuários não conseguem usar, operadores não conseguem rodar e maintainers não conseguem mudar, não está pronto.

O produto passa quando o fluxo é claro, as ações arriscadas ficam visíveis e outro maintainer consegue alterar sem adivinhar.
